# Privacy

Juicy Folder Meter works locally on the user's Windows PC. It scans local folder metadata and file sizes in order to calculate folder-size status and display that status in the application and, where Windows permits it, as Explorer icon overlays.

**This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.**

The application does not include advertising, analytics, telemetry, user accounts, or cloud synchronization.
